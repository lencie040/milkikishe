# ✦ ミルキキシェーの全界鉄道

現実の時刻に同期する、架空の鉄道会社の運行ダッシュボード。HTML / CSS / JavaScript と同梱の Three.js による静的サイトです。

## 運行設定

- 車両：全界星軌10型-001編成。動力・客室一体の1両、旅客定員24名＋乗務員1名。
- 下り：汽界 → 綿界 → 菓界 → 妖星。上りは逆順。同じ1両が往復します。
- 区間所要時間：3分30秒、4分、4分30秒。中間駅45秒、終点90秒停車。往復30分。
- 毎時00分・30分に汽界、15分・45分に妖星を発車。24時間運行、表示は日本時間。
- 時計から位置を直接計算するので、再読み込みやタブ復帰時にもダイヤに同期します。端末時計が基準です。
- 最高速度120,000 cは架空の星界航行速度です。現実の物理に世界線移動の必要速度は定義されていません。
- 星10のレー族ミルキキシェーが、星8以下の旅人を保護して世界線を渡ります。旅客数は14〜22名の決定的なシミュレーション。

## 画面

追跡カメラ（ドラッグで回転）、前方展望、客室、乗務員室。星の軌道、光のゲート、蒸気、乗客をリアルタイム3Dで描画。車内に表示する8体は旅客の代表モデルです。人物・車両は独自の仮モデルで、公式キャラクター素材は使っていません。

映像停止ボタンは視覚的な動きだけを停止し、現実時刻の運行は継続します。OSの動きを減らす設定も初期状態に反映します。WebGLが利用できない場合もダイヤと運行情報は利用できます。字体はGoogle Fontsから取得し、オフラインではシステム字体に切り替わります。3Dライブラリは同梱しています。

## ローカル起動

```sh
npm start
```

http://localhost:4173 を開きます。Python 3が必要です。HTMLを直接ダブルクリックするとブラウザのES Modules制約があるため、HTTPサーバーで開いてください。

```sh
npm test
```

Node.jsでダイヤの連続性・所要時間・折り返し・日本時間の日付境界を検証します。
